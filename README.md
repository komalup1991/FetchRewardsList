# FetchRewardsList App

This project is a simple Android app built using Jetpack Compose that displays a grouped and sorted list of items fetched from a remote API.

---

## APK Location

The release APK can be found at:
[app-release.apk](https://github.com/komalup1991/FetchRewardsList/tree/main/app/release)


## Install the APK

`adb install app-release.apk`
